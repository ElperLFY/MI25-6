# MI25-6

**MI25-6** è un progetto web indipendente che rende più semplice consultare le mappature Infratel delle reti fisse e confrontare i dati territoriali.

- **[Apri il sito MI25-6](https://elperlfy.github.io/MI25-6/)**
- **[Leggi il Tutorial completo](Tutorial.md)** — guida alle funzioni, ai dataset e al loro significato.
- [Codice sorgente](https://github.com/ElperLFY/MI25-6)
- [Segnala un problema](https://github.com/ElperLFY/MI25-6/issues)

MI25-6 non è un servizio ufficiale di Infratel, AGCOM o di un operatore e non verifica la vendibilità commerciale in tempo reale.

> **Avviso di manutenzione:** se raggiungendo l'indirizzo del sito MI25-6 al posto dell'applicazione compare questa pagina, significa che la pubblicazione del sito non è andata a buon fine oppure che la pagina ha fallito i controlli previsti. In questo caso il servizio è temporaneamente in manutenzione. La visualizzazione del README nella pagina principale del repository GitHub, invece, è normale.

Il README è soltanto una pagina introduttiva. Per le istruzioni d'uso, la spiegazione dei dati e i dettagli delle funzioni consulta il [Tutorial completo](Tutorial.md).
