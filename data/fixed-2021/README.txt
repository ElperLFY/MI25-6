La mappatura reti fisse 2021 è pubblicata da Infratel come ZIP regionali separati, non come archivio nazionale unico.

Nel repository MI25-6 sono attualmente inclusi questi archivi:
ABRUZZO.zip, BASILICATA.zip, CALABRIA.zip, CAMPANIA.zip, EMILIA-ROMAGNA.zip, FRIULI-VENEZIAGIULIA.zip, LAZIO.zip, LIGURIA.zip, MARCHE.zip, MOLISE.zip, PUGLIA.zip, SARDEGNA.zip, SICILIA.zip, TOSCANA.zip, TRENTINO-ALTOADIGE.zip, VALLEDAOSTA.zip.

Non sono inclusi nel pacchetto attuale gli archivi di Lombardia, Piemonte, Umbria e Veneto. Questa nota descrive esclusivamente i file presenti in questo repository e non afferma che tali archivi non siano mai stati pubblicati da Infratel.

Il loader scarica direttamente il file della Regione selezionata. Non creare un unico italia.zip: i file regionali pesano complessivamente circa 151 MiB e un archivio unico supererebbe il limite di 100 MiB per file nei normali repository GitHub.
