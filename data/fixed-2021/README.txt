La mappatura reti fisse 2021 è pubblicata come ZIP regionali separati, non come archivio nazionale unico.

Il loader scarica direttamente il file della Regione selezionata. Nomi presenti nel branch:
ABRUZZO.zip, BASILICATA.zip, CALABRIA.zip, CAMPANIA.zip, EMILIA-ROMAGNA.zip, FRIULI-VENEZIAGIULIA.zip, LAZIO.zip, LIGURIA.zip, MARCHE.zip, MOLISE.zip, PUGLIA.zip, SARDEGNA.zip, SICILIA.zip, TOSCANA.zip, TRENTINO-ALTOADIGE.zip, VALLEDAOSTA.zip.

Nel branch al momento non risultano archivi per Lombardia, Piemonte, Umbria e Veneto; per queste Regioni il dataset 2021 viene segnalato come non disponibile. Non creare un unico italia.zip: i file regionali pesano complessivamente circa 151 MiB e un archivio unico supererebbe il limite di 100 MiB per file nei normali repository GitHub.
